# EVE Frontier // Saints Asteroid Matrix

A lightweight desktop companion tool built for EVE Frontier playtests, featuring a live session mining yield tracker, interactive asteroid rock archetypes, and a material refinement matrix.

---

## Features

* **Live Mining Session Tracker:** Automatically monitors your local EVE Frontier `Gamelogs` folder, parses real-time mining yields, calculates session percentages, and lets you manage or clear active items[cite: 7, 8, 9].
* **Rock Archetype & Drop Matrix:** Field guide covering discovered asteroid types (Flint, Bone, Spall, Pitch, Mire, Grist, Murk, Soot, Ember), belt classifications, and exact material drops[cite: 7, 8, 9].
* **Material Refinement Matrix:** Detailed breakdown of raw material refinement outputs[cite: 7, 8, 9].
* **Desktop Export:** Save clean, timestamped summary reports directly to your Desktop as text files[cite: 7, 8, 9].
